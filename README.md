SegmentsAI is a premium analytics dashboard where **Python** handles the heavy lifting. It uses Machine Learning to transform raw customer data into actionable business segments.

## 🧠 The Python AI Engine
Unlike basic dashboards, this project uses a professional **Python** stack to perform deep data analysis:

*   **Machine Learning**: Uses `scikit-learn`'s **K-Means Clustering** to automatically group customers based on behavior.
*   **Data Processing**: Powered by `Pandas` and `NumPy` for efficient CSV parsing and mathematical operations.
*   **High-Speed API**: Built with `FastAPI`, ensuring the transition from raw data to visual charts is near-instant.

---

## ✨ Features
- **AI-Driven Clustering**: Automatically groups customers based on spending habits and tenure.
- **Interactive Visuals**: Real-time charts for segment distribution and contract types.
- **Premium UI**: Modern "Dark Red" aesthetic with glassmorphism effects.
- **FastAPI Backend**: High-performance Python backend for data processing.

## 🛠️ Technology Stack
- **Backend**: Python 3.x, FastAPI, Uvicorn
- **ML Libraries**: Scikit-Learn (K-Means), Pandas, NumPy
- **Frontend**: HTML5, CSS3 (Glassmorphism), JavaScript (ES6+), Chart.js

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rkiranmayisai/Customer-segmentation.git
cd Customer-segmentation
```

### 2. Install Python dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Python server
```bash
python main.py
```

### 4. Access the dashboard
Open [http://localhost:8000](http://localhost:8000) in your browser.

## 📊 Sample Data
You can test the application using the provided `sample_customers.csv` file. Simply upload it via the dashboard to see the AI analysis in action.
